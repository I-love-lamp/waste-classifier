About this project

Waste Sorter tells you which bin an item belongs in from a single photo: organic (brown bin) or recyclable (blue bin). It uses a convolutional neural network trained on 22,564 labelled photos from the Kaggle Waste Classification dataset. For each photo the model returns a probability for both classes. The bin shown is the more likely one, and anything under 75% confidence is flagged "Not sure" so you can check it by hand.
